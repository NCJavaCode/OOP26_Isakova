# OOP26_Isakova

## Про проект
Програмне забезпечення для продажу квитків у кінотеатр.
Програма зберігає інформацію про фільми, кінозали та квитки на сеанси.

## Навіщо цей проект
Навчитися програмувати мовою Java та опанувати принципи
об'єктно-орієнтованого програмування (інкапсуляція, абстракція, наслідування, поліморфізм).

## Класи
- Movie - фільм (назва, тривалість, вікове обмеження); реалізує інтерфейси Nameable, Printable
- Hall - кінозал (номер залу, кількість місць); реалізує інтерфейси Nameable, Printable
- Ticket - квиток (ряд, місце, ціна); має перевантажені конструктори та методи printInfo
- Show - абстрактний клас "показ" (спільні дані та поведінка для всіх видів показів у кінотеатрі)
- Cartoon - мультфільм, спадкоємець класу Show (додатково: формат 3D); перевизначає printInfo()
- Concert - концерт, спадкоємець класу Show (додатково: виконавець); перевизначає printInfo()

## Інтерфейси
- Nameable - інтерфейс від викладача: отримати та змінити назву класу (className)
- Printable - власний інтерфейс: вивести інформацію про об'єкт на екран
